# 红石LIB（Redstone Chan Lib）

一个给自己用的 Minecraft NeoForge 1.21.1 前置库，把常用功能做成能直接抄的接口，别的模组想用就写几行。

## 提供的功能

### 通用注册设施

方块、物品、粒子等常用注册的简化写法，省掉一堆样板代码。

### 自定义传送门

框架方块、激活物品或流体、门方块的颜色与名称、目标维度全部写在数据包里，Java 也能直接注册。支持竖直的门（像下界门）、平铺在地面的门（像末地传送门），以及暮色森林式的仪式激活（流体池、外圈框架、丢物品、打雷点亮）。

### 生物描边

给实体加一圈轮廓，有发光、黑色、高光三种样式，都能选纯色或彩虹，可调粗细，可决定是否透墙显示，服务端设置并存档。

### 方块描边

同样的三种样式，另外还有机械动力风格的方框和细线框，带淡入淡出动画。

### 方块与实体扫描高亮

扫描周围一定半径内的方块或实体，只给匹配的加描边，可以按方块、按标签分别指定颜色。

### 带分区的创造模式物品栏

创造栏里可以给一个页签分区，每个分区有自己的图标、提示和选中状态。

### 流体碰撞配方

流体碰流体、流体碰方块时产出别的方块或物品，可以要求碰撞位置下方有指定方块，可以配置是否消耗原料和流体源头，数据包与 Java 两种写法都支持，还带了 JEI 显示。
